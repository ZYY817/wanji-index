# V3 视觉审查与优化方案

审查方式：本地 dev（1440×900）逐屏截图浏览首页 7 章 + 游戏库 / 游戏详情 / 免费 / 资源站 / 工具，并用脚本量化首页文字。日期 2026-10-24。

## 一句话结论

视觉方向（放映厅黑、宋体巨字、游戏美术当光源、Hero→海报墙的连续过场）是对的，要保留。乱的原因不是“特效太多”，而是**信息层级被拍平**：每一屏都塞了 5–10 个同等音量的小元素（mono 编号、英文副标、计数、时钟、刻度），主角反而不突出。第 3 屏开始，“每屏只讲一件事”的原则失守。

## 量化证据（首页）

| 指标 | 现状 | 目标 |

## 问题清单（按严重度）

### P0 · 缺陷（看起来像 bug）
1. **游戏详情页全部报错**：`src/app/games/[slug]/page.tsx` 引用的 `@/components/game/game-logo` 文件不存在（约 21:47 被删）。已临时补回最小实现。
2. **计数从 0 开始**：海报墙进入时显示 `000`、目录显示 `00 个资源站`。快速滚动的用户看到的就是 0。应改为：SSR 和初始态显示真实数字，只在入视口时做短距离滚动（例如从 n-8 到 n）。
3. **乱码解码动效残留**：档案章第 5 步「存档路径」在滚动中被方块字符替换，像渲染错误。
4. **雷达表盘与卡片不同步**：横向滚到第 5 张（Apex，永久免费）时，左侧表盘仍显示第 1 张的倒计时；且表盘显示 `00:24:54`，卡片显示 `05 天 00:24:54`，同一数据两种读法。
5. **无美术的卡片显示 “NO KEY ART” 占位**：在主视觉位置显得像加载失败。
6. 顶栏章节指示滞后：已进入目录章时仍显示「04 雷达」。

### P1 · 层级与文字（“看不清”的主因）
7. **顶栏**：中间同时有「Nº 01 开映」章节指示 + 「01 游戏库 ²²」编号 + 上标计数，导航文字是 13.5px 灰色，比旁边的装饰更弱。用户第一眼找不到导航。
8. **中英双语副标泛滥**：`档案 / DOSSIER`、`CHANNELS / MODS / TOOLS`、`FREE FEED`、`RADAR ROOM`、`FILTER INDEX`、`RICHNESS`、`TIME LEFT`……英文只是重复中文，却占用了视觉注意力。
9. **Hero 首屏约 14 个独立信息点**（Nº 001、PC 游戏·原始来源、022/019/015、拼音、竖排、第二幕 02/04、搜索、轮播点、暂停、01/07、滚动提示、FIG 图注、构建日期……），四角都有东西，眼睛没有落点。
10. **字阶失控**：同一层级的东西字号不同（13 / 13.44 / 13.5；16.5 / 16.56），说明组件各自写死了 px 值而没有走 token。

### P2 · 布局与节奏
11. **档案章三栏冲突**：左侧巨字步骤 + 中间漂浮数字刻度列（03/01/03/02）+ 右侧档案卡 + 背景幽灵大字。中间的数字列与左右都不对齐，是最“乱”的一处。
12. **免费雷达太长太满**：15 张卡逐张横滑 6.5 屏；同屏有表盘、大倒计时、卡片倒计时、统计、时间轴、实时时钟 6 个焦点。
13. **章节之间是硬切**（`border-t` + 新背景），只有 Hero→海报墙有连续过场。你喜欢的那种“丝滑”正来自这个连续性，后面的章节缺少它。
14. **内页 Masthead 右侧装饰件和下方内容重复**：游戏库的「Contact Sheet」= 下方海报前 6 张；工具页的「Register」= 下方 8 个工具；资源站的「Source Ledger」= 下方列表。真实内容被挤到首屏以下。
15. **导航名与页标题不一致**：导航「资源站」→ 页面「来源目录」；「免费」→「免费 雷达」。

### P3 · 游戏库体验
16. 海报卡只有「编号 + 名称 + 类型」，看不出这款游戏**有什么**（有没有 MOD/汉化、存档路径、是否在免费、有几条入口）。用户只能一个个点进去。
17. 筛选栏 18 个类型两列铺开，每个带 9px 计数，读起来像表格噪音；排序项带英文副标（RICHNESS/UPDATED/NAME）。
18. 列表视图点击区域与卡片视图切换按钮挨得太近（测试时误点进了详情）。

## 改造方案

### A. 建立“三层音量”规则（全站）
- **主角**（每屏 1 个）：宋体大标题或游戏美术。
- **正文**（每屏 1–2 块）：15–17px，fg-1/fg-2，中文。
- **注释**（每屏 ≤ 3 处）：mono 11–12px，只放真正有用的元数据（数量、日期、域名）。
- 英文副标全部删除，只保留章节号 `Nº 03` 这一个母题；需要时用中文。

### B. 字阶 token（替换 51 种字号）
`12 · 13 · 15 · 17 · 20 · 26 · 36 · 56 · 88 · display(clamp 120–240)`，在 `globals.css @theme` 中定义为 `text-meta / text-small / text-body / text-lead / text-h4 / text-h3 / text-h2 / text-h1 / text-display-m / text-display-xl`，组件里禁止写 `text-[9px]` 这类任意值。最小可读字号 12px。

### C. 顶栏
左：字标（去掉 `WANJI / IDX` 副标）；中：`游戏库 · 免费 · 资源站 · 工具 · 教程 · 装机`，15px、fg-1、当前项下方 2px 橙线；去掉编号和上标计数；右：搜索。首页章节指示从顶栏移到**屏幕左侧细竖向进度轨**（7 个刻度，当前章节名淡入），首页和内页导航位置完全一致。

### D. 首页逐章
| 章 | 保留 | 删除 / 改 |
|---|---|---|
| 1 Hero | 背景美术、巨字「玩机索引」、一句价值主张、搜索条 | 拼音、竖排、FIG 图注、第二幕计数、三组计数、轮播点（改为美术自动淡切）、构建日期；漂浮海报 3→2 张 |
| 2 海报墙 | 全部（做得最好） | 计数初始值修正 |
| 3 档案 | 左步骤 + 右档案卡 | 删中间数字列、背景幽灵字、英文副标、乱码动效；档案卡只展开当前步骤的一行，其余收起为一行标题；步骤字号降一级（当前项大，其余 20px） |
| 4 免费雷达 | 倒计时卡片 | 只展示最紧迫的 4–5 张，横滑总长 ≤ 2.5 屏；删表盘或让表盘跟随当前卡片；每张卡只有一处倒计时；时钟/统计/时间轴三选一；无美术时用游戏海报或 TextCover |
| 5 目录 | 纸面反白、字母索引目录 | 计数修正；域名改 mono 正体；两行跑马灯减为一行 |
| 6 装机 | 全部 | — |
| 7 片尾 | FIN + 美术填充字 | 原则跑马灯减速 |

### E. 动效节奏（“精确到秒”）
- 统一 2 条缓动、3 个时长：`ease-out-expo cubic-bezier(.16,1,.3,1)`、`ease-in-out cubic-bezier(.65,0,.35,1)`；`200ms` 微交互 / `600ms` 元素入场 / `900ms` 章节过场；stagger 固定 60ms。写成 `src/components/fx/tokens.ts`，所有 motion 组件引用。
- 每章入场只做一件事：标题逐行遮罩揭示 → 300ms 后正文淡入 → 主视觉跟随滚动。禁止同一屏多处同时动。
- 章节交接借用 Hero→海报墙的手法：上一章主视觉缩小/变暗的同时下一章背景从底部推入（scroll-linked，0.0–0.15 进度区间），替代硬分隔线。
- 去掉乱码解码（scramble）在正文和标题上的使用，只留在导航 hover。

### F. 内页
- Masthead 统一：左标题 + 一句说明 + 1 个关键数字；**删除右侧重复预览件**，内容上移到首屏。
- 页标题与导航同名。
- 游戏库卡片：海报下方加「能力徽标行」（MOD · 汉化 · 存档 · 免费中）和「N 个入口」；hover 时海报上叠出 3 条最常用入口。筛选栏：类型默认显示前 8 个 + 「更多」，排序改成顶部分段控件，去掉英文。列表视图改为真正的表格（游戏 / 类型 / 渠道 / MOD / 工具 / 教程 / 核验日期）。
