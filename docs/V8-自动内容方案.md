# V8 · 自动内容方案（无服务器的内容聚合）

> 目标：网站部署在免费静态托管上，没有服务器，也能让内容**自己长起来**——
> 游戏信息、价格、存档位置、MOD 入口、免费情报、常见问题的解决方法，都从**正规公开的数据源**自动收集，
> 每条都标明来源并链接回原站（为原站引流），定时自动更新。

---

## 一、原则（所有自动收录的内容都遵守）

1. **只收正版游戏与正规来源。** 来源限定为：官方商店与平台、开发者 / 发行商官网、公认的社区百科与 MOD 平台、正规游戏媒体。
   不收录破解版、盗版下载、绕过付费的解锁工具、私服。
2. **链接 + 我们自己写的一句话摘要，不搬运原文。**
   攻略、问题解答的正文属于原作者；我们只做「这个问题在哪里有答案」的索引：标题、一句话说明、来源、链接。
   纯事实数据（存档路径、价格、发售日期、兼容评级）可以直接展示，但必须注明来源。
3. **每条都标来源与更新时间。** 自动收录的内容显示「来源：PCGamingWiki · 自动更新于 2026-10-26」这类标注；
   与人工核验过的内容在页面上可区分（`reviewStatus: "unverified"` + 来源字段）。
4. **人工数据优先。** 同一字段人工填写过，自动同步不覆盖。
5. **遵守各数据源的使用条款**：频率限制、署名要求、需要申请的 API Key（见第三节）。

---

## 二、整体结构：定时脚本 + 静态构建

```
GitHub Actions（每天定时，无需服务器）
   └─ scripts/sync/*.mjs          从各数据源拉取 → 规范化 → 写入 data/auto/
   └─ npm run build              校验 + 构建静态站（人工数据 data/ 与自动数据 data/auto/ 合并）
   └─ 部署到 Cloudflare Pages      （或任意静态托管）
```

- **`data/`** 保持现状：人工整理、人工核验的内容。
- **`data/auto/`**（新增）：脚本生成，可随时整体重建；不手改。
- 合并规则写在 `src/lib/data.mjs`：同一游戏以人工数据为准，自动数据只补空缺字段。
- 每个同步脚本独立运行、独立失败——某个数据源暂时不可用，不影响其他部分和网站上线。
- 同步后自动跑一遍外链巡检与数据校验；失败只发提醒，不阻断上一次成功的版本。

## 三、数据源与能补的内容

| 内容 | 数据源 | 方式 | 条款要点 |
|---|---|---|---|
| 游戏基本信息：中文名、简介、类型、开发商、发售日、系统要求、海报 | Steam 商店公开接口 `store.steampowered.com/api/appdetails?appids=&l=schinese&cc=cn` | 按 appid 拉取 | 公开接口，控制频率（约每 1.5 秒 1 次）；美术图片按惯例引用 Steam CDN |
| 收录哪些游戏（热门榜） | SteamSpy `steamspy.com/api.php?request=top100in2weeks`、Steam 热销榜 | 每周取一次 | 公开接口，注明来源 |
| 当前价格 / 史低 / 各平台比价 | IsThereAnyDeal API | 按游戏查询 | 需免费申请 API Key；注明来源 |
| 存档位置、配置文件位置、常见问题修复 | PCGamingWiki（MediaWiki API / Cargo 查询） | 按 Steam appid 查询 | 内容为 CC BY-NC-SA：网站非商业 ✓，必须署名并链接原页面 |
| 免费情报：Epic 每周免费 | Epic 公开接口 `freeGamesPromotions` | 每天 | 公开接口 |
| 免费情报：Steam / GOG 限免 | IsThereAnyDeal 限免列表、GOG 公开接口 | 每天 | 同上 |
| MOD 专区与热门 MOD | Nexus Mods API（需 Key）、Steam 创意工坊页面链接、ModDB 搜索链接 | 每周 | Nexus 需申请个人 API Key，遵守频率；其余只生成链接 |
| Linux / Steam Deck 兼容 | ProtonDB 摘要接口、Steam Deck 认证状态 | 每周 | 注明来源 |
| 汉化 | Steam 商店的「支持语言」字段（官方中文）；官方汉化公告 | 随游戏信息 | 只收官方中文与平台内汉化（如创意工坊汉化 MOD 的链接） |

## 四、「问题的解决方法」怎么聚合

把它做成一张**问题 → 答案在哪里**的索引，而不是转载攻略：

```
问题（我们写）：「启动黑屏 / 闪退」
适用游戏：艾尔登法环
答案在这里：
  · PCGamingWiki「艾尔登法环 · 问题修复」 — 官方补丁后的黑屏处理（一句话摘要，我们写）
  · Steam 社区指南「……」                    — 一句话摘要
  · 官方客服 FAQ                             — 一句话摘要
```

来源优先级：
1. 官方：开发商 / 发行商支持页、Steam 官方公告、微软 / NVIDIA / AMD 官方支持文档；
2. 社区百科：PCGamingWiki（有结构化的「问题修复」章节，可半自动提取标题与链接）；
3. 社区讨论：Steam 社区指南、Reddit、NGA、贴吧等——**只收链接与我们写的一句话摘要**，由人或 AI 筛选质量后收录。

站内已有的「教程」继续保留为**我们自己写的完整步骤**（高频通用问题，如缺 DLL、运行库）；
「问题索引」用来覆盖长尾问题，数量可以很大。

## 五、页面上的变化

- 游戏详情：新增「价格」（当前价 / 史低 / 各平台）、「兼容性」（Steam Deck / Linux）、「常见问题索引」三块；
  存档位置自动补全；所有自动内容带来源与更新日期。
- 游戏库：数量从 22 扩到数百；筛选增加「有官方中文」「Steam Deck 可玩」「当前打折 / 免费」。
- 免费游戏：完全自动更新，不再需要手工维护。
- 关于页：说明数据来源、自动更新机制、各来源的署名，以及「信息有误 / 希望移除」的反馈方式。

## 六、分阶段实施

| 阶段 | 内容 | 谁来做 |
|---|---|---|
| **P1 管线骨架** | `data/auto/` 与合并规则；Steam 游戏信息同步；PCGamingWiki 存档路径同步；Epic 免费情报同步；GitHub Actions 每日任务；页面上的来源标注 | Claude（结构性工作，一次做对） |
| **P2 扩充游戏库** | 用热门榜选出第一批 200 款；逐款跑同步、抽查质量；补「官方中文」筛选 | Claude 出任务文档 → 其他 AI 执行 → Claude 验收 |
| **P3 价格与 MOD** | IsThereAnyDeal 价格 / 史低、Nexus MOD 入口、ProtonDB 兼容 | 同上（需要你先申请 ITAD 与 Nexus 的免费 API Key） |
| **P4 问题索引** | 问题 → 答案在哪里的索引；先覆盖热门游戏的启动、闪退、性能、存档类问题 | 其他 AI 批量整理链接与摘要 → Claude 验收 |

需要你做的准备：
1. 把项目推到 GitHub（定时任务运行在 GitHub Actions 上）；
2. P3 之前申请两个免费 API Key：IsThereAnyDeal、Nexus Mods（我会写申请步骤）；
3. 确认部署平台（Cloudflare Pages 可直接连接 GitHub 仓库自动部署）。
