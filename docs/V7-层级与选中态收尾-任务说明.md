## 一、这一轮要解决的两个问题

1. **选中态的「左侧竖条」是典型的 AI 模板风格，全部去掉。**
   列表悬停、分类侧栏当前项、筛选当前项、提示框，原来都用一条彩色竖条标在左边。
   新规则：
   - 列表行悬停 / 键盘聚焦：整行底色变亮（`hover:bg-card`）+ 标题变香槟金 + 箭头移动；**没有竖条**。
   - 分类 / 筛选的当前项：圆角浅底 `rounded-sm bg-surface-2 font-medium text-foreground`；未选中 `text-fg-2 hover:bg-surface-2/50 hover:text-foreground`。
   - 提示框（报错原文、预期结果、使用前须知）：完整的细边框浅色底，例如 `rounded-sm bg-ok/[0.06] px-4 py-3 ring-1 ring-ok/20`；**不用 `border-l-2`**。

2. **详情页「主标题和副标题都是一样的文字，分不清主次」。**
   原因：分节标题（如「MOD 与汉化」）和其下条目标题（如「星露谷物语 MOD 专区」）都用宋体粗体，只差一个字号；条目标题还重复页面本身的游戏名。
   新的字体层级规则（全站统一）：

   | 层级 | 用途 | 样式 |
   |---|---|---|
   | L1 | 页面标题 | 宋体 `font-serif` 44–56px 粗黑 |
   | L2 | 分节标题（SectionHeading） | 宋体 `font-serif` 26–32px 粗 + （条数） |
   | L3 | **条目标题**（列表行、步骤、卡片标题） | **黑体**（默认字体，不加 font-serif）`text-lg`–`text-xl` `font-semibold` |
   | L4 | 说明文字 | `text-base text-fg-2` |
   | L5 | 元信息（来源、日期、步骤数） | `text-sm text-fg-3`，日期用 `font-mono text-2xs` |

   **一句话：标题的声音用宋体，内容的声音用黑体。** 条目标题不能再用 `font-serif`。
   另外：在某款游戏自己的档案页里，条目标题去掉开头的游戏名（已在 `src/lib/game-detail.ts` 的 `withoutGame` 实现）。
