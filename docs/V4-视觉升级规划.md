## 二、艺术方向：暗场光雕

一句话：**暗色展厅里，一束暖光打在一件雕塑上。**

- **底色**：保持暖炭黑 `#131211`。不改回纯黑，也不整站改成亮色——游戏美术在暗场里最好看。
- **光**：每一章都有一个明确的光源方向（左上斜射），用大面积、极低透明度的暖色渐变模拟「光束」，而不是发光特效。
- **主体**：引入一件贯穿全站的签名物件——**「档案之环」**：一枚半透明玻璃环 + 一块碎裂的石片 + 一条香槟金的细轨道。它是网站的视觉标识，在首屏、档案章、装机章、片尾以不同角度出现，像同一件雕塑在展厅里被不同灯光照亮。
- **强调色**：只有香槟金 `#D8B67A`，用于轨道线、节点、主按钮、当前态。
- **字**：中文标题用思源宋体；小标签用无衬线、加宽字距（如「运 行 库 体 检」）。**不加英文副标**——参考图里的英文小字是它的风格，但我们之前已经确认要去掉中英混排，所以只借「宽字距」这个手法。
- **构图**：中轴对称为主（首屏、片库、档案、装机），只有免费章用左右分栏打破节奏。

## 三、首页逐章分镜（含时间轴）

滚动进度用百分比表示该章节自身的进度；时长用于非滚动驱动的入场动画。

### 0 · 开场（新增，约 1.6 秒，只在首次访问时播放）
1. 0–0.6s：暗场中一条金线从中心画出一个圆（档案之环的轮廓）
2. 0.6–1.2s：圆环内数字 0 → 22 滚动，下方淡入「玩机索引」
3. 1.2–1.6s：上下两块幕布向外拉开，露出首屏
- 第二次访问起跳过；reduced-motion 下不播放。

### 1 · 首屏（保留现有结构，提升质感）
- 标题改为**逐行遮罩揭示**（每行从下方升起，间隔 90ms），替代整体淡入。
- **三层鼠标视差**：背景美术 ±12px、标题 ±6px、搜索框 0（越近越稳）。
- 搜索框加**磁吸效果**：鼠标靠近 80px 内时轻微被吸过去。
- 背景切换由「淡入淡出」改为**从左向右的光带擦除**（clip-path），配合光源方向。

### 2 · 片库（重做）
- **三层景深**：后层小海报（模糊 2px、速度 0.4）、中层（速度 0.7）、前层大海报（速度 1.0，只有 6 张，偶尔从画面边缘掠过）。
- **鼠标聚光灯**：光标位置有一个柔和的亮区，其余海报略暗；光标下的海报轻微抬起并显示游戏名。
- 中央：「22」单独一行严格居中，下方「款游戏」，再下方按钮；数字在滚到 15–40% 时从 0 计数上来，同时海报从边缘涌入。
- 滚到 80% 后：整面墙向后退并变暗，为第 3 章的开场让位。

### 3 · 一款游戏，四个答案（精修）
- 背景从游戏美术换成**档案之环**（AI 渲染图，见 §五-P2），游戏海报嵌在环的中心，像被托在展台上。
- 0–15%：星露谷 Logo + 引子（保留）
- 15–35%：环从远处推近并旋转到正面，海报在环心升起
- 35–60%：四张卡依次飞出，每张卡落位后**内容逐行显现**（标题 → 第一行 → 第二行，间隔 60ms）
- 连线改为**「节点—折线—节点」**：从海报边缘出发，经一个折角到卡片，两端是小圆点（参考图 2 的引线形式），线条随滚动描绘
- 60–100%：四张卡**轮流高亮**（每 10% 切换一张，高亮卡亮起金色细框，其余降到 60% 透明度），标题与入口浮现
- 卡片样式：1px 发丝边框 + 极淡的暖色内渐变 + 左上角的金色节点；不再用实心方块

### 4 · 此刻，免费的（重排）
- 左 1/3 吸顶：大标题「此刻，免费的。」、当前这张卡的游戏名与截止时间（随画廊滑动切换）、一条纵向进度、「全部免费情报」入口
- 右 2/3：画廊，卡片高度约 62% 屏高，宽度约右栏的 85%，右侧露出下一张的边缘提示还能继续
- 每张卡进入时：美术从 1.08 缩放到 1，倒计时数字逐位翻入

### 5 · 资源站（重做，二选一）
- **方案 A · 暗场 Logo 星图**：19 个官方 Logo 分布在一个缓慢旋转的三维椭圆轨道上（参考图 2 的「球体 + 四角标签」构图），滚动时轨道转动、Logo 依次经过前景放大；下方是分类网格。全程暗场，与前后章节无缝。
- **方案 B · 光铺开的亮章**：保留米白纸面，但进入方式改为**以屏幕中心为原点的圆形光斑扩散**（clip-path circle 0% → 150%），像一束光把展厅照亮；离开时同样收回。亮色只在这一章出现，作为全片唯一的「白昼」。

### 6 · 装机工具（按参考图的语言重做）
- 这一章**整体改为亮色展台**（参考图 1–4 的暖白空间 + 斜射光），因为它介绍的是一个独立软件，用不同的「空间」区分最合适。
- 中央是装机工具的签名物件（玻璃环 / 球体，AI 渲染，见 §五-P3），四角用折线引出「VC++、DirectX、.NET、Vulkan」，正下方一个圆形「开始检测」按钮（演示用）。
- 滚动时：物件缓慢旋转 15°，四个标签依次亮起，最后出现「开发中，敬请期待」。

### 7 · 片尾
- 档案之环的俯视剪影作为背景水印，金线缓慢旋转；字标「玩机索引」用光带扫过一次。

## 四、全站交互与动效规范

| 类别 | 规则 |
|---|---|
| 滚动 | Lenis 平滑滚动，惯性系数 0.08；所有章节的滚动动画只用 transform / opacity / clip-path |
| 缓动 | 入场 `cubic-bezier(.16,1,.3,1)`；过场 `cubic-bezier(.65,0,.35,1)`；悬停 200ms、入场 600ms、过场 900ms |
| 文字 | 大标题一律「逐行遮罩揭示」；数字一律「从下翻入」；正文淡入 + 上浮 24px |
| 图片 | 首次出现用 clip-path 从下向上揭开（700ms），揭开同时图片从 1.1 缩放到 1 |
| 鼠标 | 卡片 3D 倾斜 ≤ 6°，并有一道随鼠标移动的高光；按钮磁吸 ≤ 8px；链接下划线从左向右划出 |
| 光标 | 可选：一个 8px 的金色小圆点跟随光标，悬停在卡片上时放大成「查看」圆标（触屏不启用） |
| 页面切换 | 点击站内链接：一条金线从左划到右，同时页面淡出；新页面标题逐行揭示进入 |
| 降级 | reduced-motion：全部静态；触屏：关闭鼠标类效果；低性能设备：关闭 WebGL，用静态渲染图 |

## 六、技术选择（待确认）

- **方案一 · 渲染图 + 视差（推荐先做）**：上面的 AI 渲染图做成多层（物件、光束、粒子分层），用现有的 Motion 做滚动与鼠标视差。轻量、稳定、所有设备都流畅。
- **方案二 · 实时 3D（WebGL）**：用 three.js 做一个真正的玻璃环，滚动时实时旋转、折射背后的海报，鼠标可以推动它。这是最接近获奖作品的做法，但会增加约 150KB 脚本、对显卡有要求、开发量大约多一倍。
- 建议：先用方案一把全站做完，再挑第 3 章一个位置升级为实时 3D，作为「点睛」。
