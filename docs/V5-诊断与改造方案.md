# V5 诊断与改造方案：为什么还不是顶级，怎么做到

日期：2026-10-25
诊断方法：首页从顶到底每 1/4 屏截一帧，共 74 帧（`.shots/film.html`）；同时用真实显卡测量滚动帧耗时。

---

## 一、结论先行

**问题不在性能，在编排和设计语言。**

- 性能：滚动中位帧耗时 3.6ms，90% 在 6.8ms 以内，整页只有 4 帧超过 34ms（首屏大图解码）。流畅度不是瓶颈。
- 编排：首页是 6 个**各自独立设计**的章节，用一个通用的「透明度叠化」拼起来。逐帧看，衔接处是两张无关画面叠在一起，中间还有大段静止的「死区」。
- 设计语言：用的是当下 AI 生成网站最常见的一套组合，所以「AI 味」重，没有自己的签名。

前几轮没做到位，我自己的原因是：一直在按每一屏的反馈局部修补，没有先画一条贯穿全片的时间轴；验收也只看静止截图，没逐帧看运动。这一版把方法改过来。

## 三、「AI 味」从哪里来

下面这些单独看都不算错，但叠在一起就是 2024–2026 年 AI 生成网站的「标准配方」：

1. **暗底 + 暖金强调色 + 衬线大标题**：现在最常见的「高级感」模板。
2. **居中三件套首屏**：小标签 → 大标题 → 一句说明 → 搜索框 → 热门标签。
3. **字距拉开的小标签**：「运 行 库 体 检」「P C 游 戏 资 源 索 引」。
4. **处处是 1px 描边卡片**：信息卡、工具卡、Logo 卡、状态板，全部是同一种盒子。
5. **圆角描边按钮 + 右箭头**、**胶囊徽标**、**圆形图标底**。
6. **等宽小字元数据**：`01 / 07`、`Windows 10 / 11 · x64`。
7. **径向暗角 + 光晕 + 玻璃**：用来「制造氛围」，但每章都一样。
8. **没有原创素材**：画面全靠游戏官方美术和代码画的占位物件，网站自己没有「签名画面」。

## 四、改造方案

### A. 一条线：共享元素的连续镜头（最核心）

Apple 产品页的丝滑感来自**同一个物体贯穿多个章节**：上一章的主角变形、移动，成为下一章的主角。不是两章叠化。

首页改为**一个固定舞台 + 一条全局时间轴**，各章是时间轴上的片段：

| 进度 | 镜头 | 共享元素 |
|---|---|---|
| 0–8% | 首屏：整屏游戏美术 + 标题 | 背景美术 |
| 8–18% | 美术缩小成一张竖版海报，退到画面中央；四周的海报从边缘涌入，拼成海报墙 | 首屏美术 = 墙中央那张海报 |
| 18–30% | 墙面倾斜、流动；「22」作为墙上的镂空字出现 | — |
| 30–40% | 墙上星露谷那张海报被「抽出」、放大、转正，其他海报退暗散开 | 墙里的一张海报 = 档案章的主角 |
| 40–55% | 海报背后升起档案之环，四张信息卡从海报边缘展开、连线 | 海报 |
| 55–62% | 四张卡收拢、叠成一张票据，飞向右侧 | 信息卡 = 免费画廊第一张 |
| 62–76% | 免费画廊：节拍式翻动（每张停 0.5 屏、切换 0.3 屏），不再匀速横移 | — |
| 76–82% | 最后一张卡缩成一个光点，光点成为星图中心 | 卡片 = 星图中心 |
| 82–92% | 星图：Logo 沿轨道快速散开再收拢成网格（分类网格是星图「落地」的结果，不再是普通滚动） | Logo |
| 92–100% | 星图中心光点扩散成亮场 → 装机展台 | 光点 |

全长压到约 **11 屏**。每一段都写清「哪个元素、在哪个进度区间、从什么状态到什么状态」，这就是「精确到秒」。

### B. 节奏规则

- 每 0.5 屏必须有一个可感知的变化；不允许超过 1 屏的静止。
- 同一时刻只有一个主动作；文字永远不和另一章的文字同时出现在画面中央。
- **全部滚动驱动**：除首屏入场和鼠标悬停外，去掉所有按时间播放的入场动画（它们是「突然出现」的来源）。
- 用逐帧胶片做验收标准：任意相邻两帧都要「看得出是同一个镜头」。

### C. 去 AI 味：新的设计语言「索引册」

| 现在 | 改为 |
|---|---|
| 暗底 + 固定金色 | **黑白为底，强调色取自当前章节的游戏美术**（悟空赭红 → 星露谷青绿 → Epic 品红……），随滚动过渡。网站本身没有「品牌色」，颜色永远来自游戏 |
| 居中三件套首屏 | 左下角不对称落版：巨型标题被画面裁切，搜索放在顶栏，不在首屏正中 |
| 描边卡片 | **去掉盒子**：用大号编号、细分隔线、留白和网格对齐来组织信息，像一本书的索引页 |
| 圆角描边按钮 + 箭头 | 文字链接 + 下划线从左划出；主操作用实心直角色块；不用胶囊 |
| 字距拉开的小标签、等宽元数据 | 删除；需要的说明用正常中文小字 |
| 径向暗角、光晕、玻璃 | 删除；氛围只来自游戏美术本身和真实的光（档案之环的 3D 光照） |
| 标准顶栏 | 极简顶栏：左字标，右「搜索」「目录」；向下滚自动隐藏，向上滚出现。「目录」打开全屏菜单：六个大号编号条目，悬停时背景换成对应栏目的代表游戏美术 |
| 鼠标默认箭头 | 自定义光标：小圆点，悬停海报时变成「查看」圆标，悬停可拖动区域时变成「拖」 |

### D. 签名素材

网站需要一样「只有它有」的东西。建议：
- **档案之环**（已有实时 3D 版）作为全站唯一的签名物件，出现在首屏角落、档案章、装机章、片尾；
- 由图像模型出 3–4 张同一光照、同一材质的渲染图（提示词见 V4 文档第五节）用作章节转场的底纹。

## 六、建议的推进方式

先做一个**样片**：只重做首页的前 3 段（首屏 → 海报墙 → 档案），用新的时间轴和新的设计语言，录一段逐帧胶片给你看。
方向确认后再铺开到后半段和内页，避免又一次全站改完才发现方向不对。

## 七、排版规则：什么时候居中，什么时候靠左（2026-10-25 补）

首页是「放映」，内页是「索引册」，两者的对齐逻辑不同：

**首页 · 一条中轴贯穿全片。** 镜头的主角（美术、海报、卡组、星图、装机物件）始终在画面正中，所有文字都围绕这条中轴安排：

| 情形 | 对齐 | 例子 |
|---|---|---|
| 画面只讲一句话、没有别的东西和它竞争 | **居中** | 首屏标题 + 搜索；章节标题；「22 款游戏」；「19 个可信来源」 |
| 文字要和中央主角一起读 | **以中轴为轴，左右对称排布** | 海报两侧的四组答案；卡组下方的倒计时 |
| 说明、署名、滚动提示等次要信息 | **贴边**（左下 / 右下角），不进入画面中心区域 | 「官方美术」署名、「向下滚动」 |
| 标题与主角会撞位时 | 标题放在主角**正上方**，入口放在主角**正下方**，仍然居中 | 档案章标题、「打开完整档案」 |

**内页 · 靠左对齐到网格。** 列表、正文、表格是要逐行读的内容，统一左对齐；只有页面级的大数字、空状态提示居中。

上一版把首屏和「22」挪到左栏是错的：首页的中心是那张卡片，文字离开中轴后，眼睛要在左边和中间来回跳，破坏了「一条线」。

## 八、首页后半段时间轴（与开场同一中轴）

| 段 | 镜头 | 交接 |
|---|---|---|
| 开场收场 | 星露谷海报缩小、退到中轴偏左，成为「上一张卡」的位置 | → 免费章卡组的左侧空位 |

## 十、第四轮：三方评审合并（视觉 / 动效 / 体验，2026-10-25）

**共同根因**：`Scene` 的「定格帧交叉溶解」= 两层半透明静帧叠加，新章自己的开场动作要等溶解结束才开始 → 浑浊、憋屈、像糊在一起。

**改法：接力（relay）**——下一章从第一帧起就是不透明的，先原样画出上一章的最后一帧，再在自己的进场窗口里完成交接：
| 交接 | 共享元素 | 动作 |
|---|---|---|
| 档案 → 免费 | 星露谷海报 | 文字与连线先退回海报；海报居中不动 → 下一章里海报翻转 90° 变横版，背面就是第一张免费卡；标题、倒计时随后进场 |
| 免费 → 资源站 | 最后一张卡 | 卡片美术褪去只剩轮廓 → 19 个 Logo 从卡片里散开飞上轨道，轨道线随之画出，「19」同步计数 |
| 资源站 → 装机 | 画面中心 | 装机章固定在视口，光从正中央扩散（不再从底部升起、顶部被切平） |
| 装机 → 片尾 | 暗场 | 只压暗不全黑，片尾随即覆盖上来，无整屏黑帧 |

**其他修正**：首屏文字先退再收缩；海报墙相邻列不重复；「22」改香槟金、说明 18px；档案标题先于四组答案、答案整行出现不再被遮罩切半、长路径换行不截断；免费章缩短为每卡半屏、两侧卡隐藏文字、「精选 6 / 共 15 条」；轨道只给最前方一个 Logo 显示名称；落地顺序改为「标题先上移 → 各列依次落下 → 该列标题出现」；资源站补眉题与标题，「其他」改为「比价与数据」；按钮统一为「主按钮：香槟金实心直角 48px，居中在主体下方」+「次要：下划线文字链」；装机 01/02 对齐、文案缩短；片尾只保留一个结尾（去掉 FIN 外环、字标改纯色低透明度、描边字改实心半透明），整体居中；首页顶栏开场镜头之后常驻；首屏补「本周限免」与「不收录破解与盗版」。
