# V2 视觉系统 · 玩机索引 —「放映厅 × 索引册」

**概念**：首页是一场**放映**——游戏官方美术是唯一的光源，思源宋体是旁白，滚动是放映机的手柄，每一屏只讲一件事；内页是一本**索引册**——编号、发丝线、mono 元数据，安静、精确、高密度。两者共享同一套字体、编号母题（Nº）、印刷对位标记与配色，全站一个声音。**界面外壳不发光，颜色只来自游戏美术。**

## 首页分镜（7 章，每章 = 信息目的｜视觉手法｜动效）
1. **Hero · 开映**｜「这里是 PC 游戏的档案馆」｜全出血 `library_hero` 背景（4 张交叉淡入，带「FIG.01 — 片名 / © 发行商」片头字幕）+ 3 张漂浮海报中景 + 超大宋体「玩机 / 索引（描边）」左下不对称落版 + 右侧竖排「只指向可信的原始来源」+ mono 元数据（Nº / 收录数 / 构建日期）+ 命令面板触发条（Ctrl K）｜三层视差速度 0.15 / 0.45 / 1.0；鼠标微视差；滚动时标题上移、背景放大变暗。
2. **海报墙 · 片库**｜「资源非常多」｜粘性 100vh 舞台里 6 列竖版海报整体 3D 倾斜，奇偶列反向错速；左下巨型描边计数「22 款」｜列 translateY 随进度 ±240px；悬停海报显示名称 + 资源计数。
3. **一个游戏，一份档案**｜「网站做什么」｜左侧宋体标题与 01–05 步骤粘性，右侧星露谷物语档案卡（真实数据）随滚动逐行点亮：渠道 → MOD → 工具 → 排障 → 存档路径｜当前行橙色刻度 + 解码文字；SSR 全部点亮，JS 后才设暗态。
4. **免费雷达**｜「现在什么免费、还剩多久」｜纵向滚动驱动横向时间轴（pin），每张为「剩余时间巨型 mono 倒计时 + 实心生命周期徽标 + 美术」，紧迫者在前且橙色时间轴｜移动端改原生横滑 + scroll-snap。
5. **资源站目录（纸面反白章）**｜「这是导航站」｜全站唯一的米白纸面章节：巨型计数 + 两行反向字母头像跑马灯 + 书后索引式目录（分类字头 + 点线引导到 mono 域名）｜计数滚动、跑马灯悬停暂停。
6. **一键装机工具 · 揭幕**｜「我们还在做一个软件」｜CSS 搭建的 Windows 工具窗从倾斜远处升起摆正（rotateX 24°→0、scale 0.82→1），检测清单逐项扫描出 ✓ / ✗ 缺失 / ! 过旧｜「开发中」明示，链接 /kit/。
7. **片尾**｜签名｜巨型「玩机索引」用游戏美术填充 + 描边，被裁切在页底；原则声明与站点信息。

## 字体与层级
- 展示：**Noto Serif SC 可变**（fontsource 本地切片）。display-xl `clamp(72px,15vw,240px)`/900/-0.055em/行高 .86；display-l `clamp(44px,7.5vw,120px)`/800/-0.045em；display-m `clamp(36px,5vw,76px)`/750/-0.035em；h2 宋体 26–30/700。
- UI：Geist Sans + PingFang SC → Hiragino Sans GB → Microsoft YaHei UI → Noto Sans SC；正文 15/1.7，密集 13.5。
- 元数据：Geist Mono 11px / 大写 / 0.14em / tabular-nums——数字、日期、域名、路径、编号。
- 尺度反差是核心：240px 宋体旁边放 11px mono。

## 间距 · 圆角 · 线
4px 基准；章节上下 160/96px（桌面/移动）；页边 `clamp(20px,4vw,56px)`；容器 1440。圆角极小：徽标 2px、控件 4px、海报 4px、窗口 10px——**编辑感来自直角与发丝线，不来自圆角卡片**。投影只给浮层。

## 母题
1. **Nº 编号**：章节 `Nº 03 — 档案`；游戏档案号 = Steam appid（`档案 Nº 413150`）。
2. **片头字幕**：美术旁的 `FIG.01 — 片名` mono 注释，像电影/画册图注。
3. **印刷对位标记**：关键面板四角 L 形裁切线（档案卡、工具窗、页头）。
4. **字母头像图章**：首字（母）+ id 哈希色相，OKLCH 同明度同彩度。
5. **点线引导**：目录行「站名 ········ 域名」，书后索引形制。

## 特殊文字手法（有目的地用）
超大宋体（Hero / 章标题 / 页标题）· 描边空心字（Hero「索引」/ 片尾 / 计数）· 美术填充字（片尾字标）· 中文竖排（Hero 侧栏、详情页片名）· 乱码解码（导航悬停、mono 元数据入场）· 数字滚动（目录与 Hero 计数）· 跑马灯（目录图章带）· 逐行遮罩揭示（章标题，仅 JS 挂载后且未入视口时设初始态）。

## 外壳
- **顶栏（全站一致）**：左宋体字标 + `WANJI/IDX`；中 mono 编号导航 `01 游戏库 02 免费 03 资源站 04 工具 05 教程 06 装机`（当前项橙色方点）；右命令面板触发 `搜索 Ctrl K`。首页叠在 Hero 上透明，滚过 80px 收为实色 + 发丝底线；内页始终实色。理由：首页需要全出血美术，内页的左侧空间留给各自的筛选/分类栏。
- **移动端**：顶栏 56px（字标 + 搜索 + 菜单）；菜单为全屏宋体编号目录抽屉（每项 ≥56px）。
- **命令面板**：`Ctrl/⌘K`、`/`；cmdk + Radix Dialog；游戏带缩略图、资源站带图章；最近访问 localStorage。

## 动效与性能
Motion 统一（`MotionConfig reducedMotion="user"`）+ Lenis 平滑滚动（reduced-motion / 触屏不启用）。只动 transform / opacity；`useScroll`+`useTransform` 驱动，不在滚动中读布局；LCP 图 eager + `fetchPriority="high"`，其余 lazy；所有美术固定宽高比容器。移动端视差层数减半、幅度 ×0.4，横向 pin 改原生横滑。**SSR 初始态所有文字可见**；揭示类动效只在挂载后对未入视口元素设初始态。

## 禁止
背景光晕 / 发光球 / 紫蓝渐变 / 玻璃拟态；「图标+标题+一行描述」卡片阵列；圆角卡片 + 投影 + 悬停上浮铺满；居中标题 + 大搜索框 + 入口卡片；emoji 图标；从头到尾 4 列网格；输入框 + 原生 select 筛选栏；全站系统黑体。
