## 1. 组件清单与规范映射

| 组件 | 规范要点 |
|---|---|
| `LifecycleBadge` | 实心胶囊轨：五态映射（进行中 success/未开始 info/已结束 neutral/截止不明·状态待确认 warning）；null 不渲染（permanent/opensource） |
| `StatusBadge` | 描边胶囊轨：linkHealth(ok 不渲染/unchecked→待核验/suspect/dead)、核验(待核验/久未核验)、步骤(亲测/社区方案未核验/未核验) |
| `AcquireButton` | 实色主按钮 H36，**仅限获取/领取**；dead=灰化禁用+徽标；移动整宽 H48 |
| `OutlineButton` | 站内导航描边次级（border-control 边+accent 字+白底） |
| `ExtLink` | 普通外链唯一形态：文字+↗+站名；dead=删除线+不可点+替代提示 |
| `SearchBar` | global H44 / inline H40 两档；border-control、focus accent |
| `IndexRow` | D2 基本单元：H64-72、行间 1px 装饰线、hover bg-sunken、移动两行式 |
| `Section` | D1 分节：H2+细分隔线；无数据由调用方整块不渲染 |
| `WarningStrip` | 警示条：左 3px warning+#FCF6EC 底（克制 amber，非红） |
| `StepBlock` | 教程步骤：28px accent 数字圆+操作/预期/若未解决+verified 徽标 |
| `TextCover` | 无图封面：首字符+accent-soft 底（list 40/detail 88） |
| `MetaDate` | mono「核验于 YYYY-MM-DD」+超阈值自动出「久未核验」徽标 |
| `SourceLine` / `FilterChip` / `EmptyState` | 来源行/可除筛选标签/空态（与错误态分离） |

**API 层面的规范固化**：生命周期与状态徽标是两个组件，形态不可传参混用——D3 双轨规则由组件边界保证而非靠使用者自觉。`AcquireButton` 命名即约束（实色用途白名单）。
