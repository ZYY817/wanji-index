# 项目上下文与储备清单

> 记录跨阶段的确认结论与"暂不开发但要保留"的想法。后续阶段以此为准。

## 已确认结论（截至第二阶段）

- 产品：面向中文 PC 玩家的游戏资源与工具索引站（暂定名「玩机索引」，名称集中在单一配置处，不写死）
- 形态：纯静态网站，SSG 生成独立 HTML，重视搜索引擎收录（百度取向 → 不用纯 SPA/hash 路由）
- 数据：JSON/Markdown 数据文件驱动，加游戏 = 加数据
- 第一阶段不做：账号/社区/评论、数据库与后端、自动下载安装、AI 助手、桌面客户端、任何变现功能（广告/联盟/网盘/付费）
- 资源原则：只收录可信来源入口，跳转原始网站，不托管第三方游戏安装包，不做破解资源索引

## 阶段储备（暂不做，已记录在案）

### 游戏运行环境诊断小工具（免费 → 引流 → 网盘推广）

- 想法：检测系统缺失的 VC++ Redist / DirectX / .NET，对照游戏需求给修复方案；免费发布，放到百度网盘供下载，通过网盘推广获得收益；后续可做官网
- 竞品现实：DirectX 修复工具（十年口碑、免费）、暴喵修复匠（按游戏匹配、加速器公司引流产品）、BoosterX GameReadyX、联想商店各类 DLL 修复工具
- 结论：该方向已被覆盖且做系统级修复工具有信任门槛（要管理员权限的来路不明 exe）。若要做，定位为轻量/信息型辅助工具更安全
- 与主项目的关系：未来可作为网站工具库中的一个原创条目引流，但明确不属于第一阶段范围（说明书禁止桌面客户端与网盘推广）

## 跨阶段备忘

- 内容差异化点：档案页中的"常见问题/报错速查"是本站与普通网址导航拉开差距的模块，数据结构里保留但设为可选，不熟的游戏不强填
- 待淘汰/延后：静态分类落地页、fuzzy 搜索、相关游戏算法、RSS、视觉设计稿
