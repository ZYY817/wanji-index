## 1. 分层校验结构（落地 docs/06 §7）

| 层 | 工具 | 覆盖 | 失败语义 |
|---|---|---|---|
| A 配置 | `config.mjs` | site/enums/redirects 解析+字段 | 阻断 |
| B 结构 | Ajv + `schemas/` | 类型/必填/格式/枚举值 | 阻断（列实例路径） |
| C 业务 | `validate.mjs` 自定义 | id/slug 唯一、Entry.siteId 必填关联存在 | 阻断 |
| C 业务 | 同上 | 可选关联悬空（gameId/supportedGames/games/tools/relatedX/faq.guideId/officialSiteId/relatedGameIds）、published 未达最低标准 | 警告不阻断 |

`x-enum` 设计：Schema 内写 `{"type":"string","x-enum":"platform"}`，加载时替换为 `enums.json` 对应数组——Schema 与 enums.json 不产生第二份枚举副本。

## 2. 过程中发现并修复的真实问题

| 问题 | 表现 | 处理 |
|---|---|---|
| `lifecycle.mjs` 判定 bug（从 M0a 带入） | 无 `startDate` 仅有 `endDate` 的 limited 记录全部误判 `uncertain`（`s===null` 时未区分 hasStart） | 条件改为 `hasStart && hasEnd && s > e`；新增 5 个回归用例后 16/16 |
| M0a 测试盲区 | M0a 用例的 endDate 场景均带 startDate，漏掉该分支 | M1 用例补齐（含仅日期 endDate、datetime 边界、weekend） |
| 测试用例自身算错 | "checkedAt 恰好 14 天内"用了 2026-10-10（实为 14.5 天前） | 改为 2026-10-11（13.5 天） |
